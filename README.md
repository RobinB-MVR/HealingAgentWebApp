# React Multi-Page App

This is a modern, minimal React web application built using functional components and hooks. The application utilizes React Router for navigation and is styled with TailwindCSS.

## Features

- Multi-page application structure
- Responsive design with TailwindCSS
- Functional components with hooks
- React Router for seamless navigation
- Placeholder pages for Home, About, Contact, and Not Found

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd react-multi-page-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```
